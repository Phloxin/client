Pylon

A desktop client for voice, video/screen-share, and text chat. Self-hosted servers, ten themes, no browser tab required.

Download Source on GitHub

Windows · macOS · Linux (AppImage, deb, snap)

Voice & video

WebRTC through a mediasoup SFU, with SVC video and live connection stats.

Screen share with audio

Native per-app or system-wide capture — WASAPI process loopback on Windows, PipeWire on Linux.

Noise suppression

RNNoise runs locally on your mic before anything leaves the machine.

Any server you like

Save as many Pylon servers as you want and switch between them instantly.

Logins stay encrypted

Credentials and saved servers are held in the OS keychain, not a plaintext file.

Auto-updates

Check, download, and install new versions from inside the app.
